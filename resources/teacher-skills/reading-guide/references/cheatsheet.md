# 一页速查 · 阅读指导

> 底本：Arnold《Reading: How to Teach It》(1899) · Project Gutenberg 公有领域

## 口诀（八字四句）

```
先问为何，再问读啥；
经验在前，文字在后；
他自己做，我少讲话；
先懂后读，带问借书。
```

## 课文研读五步（第四章，顺序不可乱）

```
独立默读 → 自己标疑 → 只讲拦路词(≤5) → 复述+3思想问 → 再读一遍
```

## 表达性朗读四步（第六章）

```
理解过关 → 划意群 → 定意图(一段一个感受词) → 试读·听评·重读
```
听评只问两句：**听懂了吗？听着舒服吗？**

## 信号 → 动作 速查

| 用户信号 | 立即动作 |
|---|---|
| 读完说不出讲了啥 | 走研读五步，禁教师代讲 |
| 朗读像念经 | 回退到"理解"，别练技巧 |
| 只看漫画/网文 | 搭桥：保留旧爱 + 每周 1 本高一档好书 |
| 低年级听不懂词 | 先上语言课/实物课，补经验 |
| 我讲了他不动 | 讲授时间砍半，改成学生任务 |
| 只会背生字表 | 教师重列"真正妨碍理解的词"≤5 个 |
| 图书馆空手回 | 用"带问题借书"六步流程 |
| 看图不说话 | 三层提问：看到什么→发生什么→你怎么想 |

## 选书三筛

1. 内容可敬　2. 语言耐读　3. 高一档但够得着（每页生词 3–5）
配比：幻想 / 自然 / 传记 / 童年生活 / 经典，各占一份。

## 禁忌（做了就倒退）

- ❌ **教师代讲**：在学生自己读之前把课文讲完。
- ❌ **技巧先行**：先教语调重音，再套课文 → 表演腔。
- ❌ **生字表照单全背**：把词表当研读的唯一基础。
- ❌ **经验空缺硬上文字**：孩子没见过的东西，讲一百遍词也是空的。
- ❌ **检索式提问刷屏**："第几段说了什么"代替思想性提问。
- ❌ **硬禁读物**：只换来偷看，品味要养不要禁。
- ❌ **背诵打分**：诗歌背诵改为"愿意背给谁听"。
- ❌ **照搬 1899 年书单**：方法可用，书目须本地化替换。

## 一节课的合格线

学生自己"做"的时间 ≥ 教师讲的时间；下课时他能用自己的话讲出这篇课文。

## 免责

仅为教学方法论建议，不构成阅读障碍等医学/心理诊断，不替代学校课程，不承诺成绩。

## 二、表达性朗读训练四步（对应第六章）

**前置门槛**：能复述大意 + 说出情绪基调。未过关**不进入**朗读训练。

| 步骤 | 做什么 | 判定通过的标准 |
|---|---|---|
| 1 理解 | 复述 + 回答 3 个思想性提问 | 复述不遗漏主线，能说出"这段在讲什么心情" |
| 2 划意群 | 用 `/` 按意思切句，不按标点切 | 切完读一遍不憋气、不断意 |
| 3 定意图 | 每段写一个感受词（急/静/惊/暖/怒…） | 能说出"作者想让听的人____" |
| 4 试读—听评—重读 | 同伴只答两问：听懂了吗？舒服吗？ | 两问皆"是"，且第二遍比第一遍自然 |

**三条禁令**
1. 不先教语调、重音、手势（会得到表演腔）。
2. 不用"读得再有感情一点"这类无操作性指令，改说"这句你想让人感到什么？"。
3. 不在全班面前纠错到底，改为同伴小范围听评。

## 三、选书原则六条（对应第二/十二/十三章）

1. **内容可敬**：读完让人变宽厚、变好奇，而非变刻薄或麻木。
2. **语言耐读**：值得读第二遍的句子；朗读起来顺口的优先。
3. **高一档但够得着**：略高于当前水平，生词密度约每页 3–5 个为宜。
4. **类型配比**（取自第十二章书单结构）：幻想文学 / 自然风物 / 传记励志 / 童年生活 / 经典史诗，各占一部分，不偏食。
5. **经检验才留**：孩子实际读完且愿意谈的留下，无人问津的换掉——书单是"tested and found helpful"，不是权威清单。
6. **搭桥不硬禁**：保留他喜欢的品类，并行引入好书换口味。

## 四、读前摸底提问表（对应第五/七章，任何主题通用）

| 提问类型 | 示例问法 | 目的 |
|---|---|---|
| 见过吗 | 你在哪儿见过它？ | 定位已有经验 |
| 会做什么 | 它会怎么样？发出什么声音？ | 检验概念清晰度 |
| 相关人事 | 谁跟它打交道？ | 建立联系 |
| 他的说法 | 你会怎么形容它？ | 采集口语词，为过渡到书面词做准备 |
| 空白点 | 关于它你最想知道什么？ | 找出可用的兴趣入口 |

---

## 五、图画/实物课三层提问（对应第九章）

1. **看到什么**（客观，目标说满 10 条）→ 训练观察
2. **发生了什么**（由细节推情节）→ 训练推理
3. **你怎么想**（感受与联想）→ 训练表达
4. 收尾：给它起个标题并说明理由

## 六、图书馆"带问题借书"流程（对应第十一章）

```
□ 出发前：自己写下 1 个想弄明白的问题
□ 到馆后：用目录/检索找到 3 本候选
□ 判断：看目录页 + 前言 + 随机试读一页
□ 借走：1–2 本
□ 一周后讲三句话：书说了什么 / 我的问题解决了吗 / 下一个问题是什么
□ 每月至少一次，固定成节奏
```

## 七、每周复盘检查表（教师/家长）

- [ ] 本周有没有让学习者**独立默读**并自己标疑？
- [ ] 我有没有在他动手之前就把课文讲完了？
- [ ] 障碍词是我判断的，还是照抄生字表？
- [ ] 朗读训练是否在"理解过关"之后才开始？
- [ ] 是否做过一次读前语言课/实物课？
- [ ] 本月图书馆（或书店/家庭书架）活动做了吗？
- [ ] 书单里是否至少有一本"他愿意主动谈"的书？

# 科学 — 分层教学法

Loaded by `k12-lesson-differentiation` when the subject is **science**（科学/物理/化学/生物）.

## 识别源课时

三种场景——检测适用哪种：

**场景 A — 对话中已有源课时**
直接使用。不要重新请教师分享。

**场景 B — 教师上传源课时**
先读取文件。确认：年级、学科核心素养、核心概念、课时结构和阶段、聚焦的科学思维方法（观察/实验/解释/建模/推理）。如果文件无法读取，清晰提示错误并请教师重新分享。

**场景 B2 — 教师通过 URL 提供源课时**
先获取 URL 并读取其内容。确认后按场景 B 处理。

**完成场景 B/B2 仅完成第一步，不代替标准锚定。**

**场景 C — 无源课时**
> "没问题。你有具体的课要分层吗？可以粘贴内容、分享文件，或者告诉我年级 + 科学领域 + 核心概念，我来做。"

## 标准锚定

遵循 **SKILL.md 第二步——锚定课标**：根据学科选择对应的课标参考文件：
- 小学科学 → `references/curriculum/science.md`
- 物理 → `references/curriculum/physics.md`
- 化学 → `references/curriculum/chemistry.md`
- 生物学 → `references/curriculum/biology.md`

使用其中的核心素养、核心概念与内容要求、学业质量标准作为锚定来源。

**教材版本检测：** 检测教师是否提及教材版本（人教版/教科版/苏教版/沪教版等）。

## 分层规则

应用以下八条规则到每一个分层的课时。

### R1 — 输出结构

**1 份整合的教师面向课时方案 + 3 份纯粹的学生练习单。**

### R2 — 范围保持

**每一层都面向原始的课标要求（核心概念与学业要求）。每一个科学思维方法（观察/实验/解释）必须在所有层级中出现。**

降低低层学生的认知范围——移除探究、用阅读代替实验、或简化现象——不是分层。

**必须保持低层的参与度。** 所有层探究相同的现象——以不同的支持，而非不同的任务。

### R3 — 通过观察→表征→解释递进实现"教上去"

| 层级 | O→R→E 递进切入点 |
|---|---|
| 低层 | 观察 → 表征（结构化，有支持），然后进入解释（有脚手架） |
| 中层 | 表征 → 解释（标准） |
| 高层 | 解释 → 延伸（概括、反例、定量化、工程应用） |

**认知冲突不可妥协。** 不要为低层学生平滑掉前概念与观察之间的冲突——帮助他们命名它：*"我原以为____，但我观察到____。现在我认为____。"*

### R4 — 低层脚手架

**目标是保护产生性挣扎，而非消除它。决不能把低层学生引离探究。**

失败模式：
- ❌ 在学生探究之前预告诉解释
- ❌ 为低层学生移除实验——让他们阅读而其他人探究
- ❌ 简化现象——所有层观察相同的现象
- ❌ 仅用读写脚手架代替科学实践脚手架

可接受的脚手架：
- ✓ **引导/分析问题** 排序观察→联系→意义
- ✓ **句子支持**："我的论点是____。我的证据是____。这支持我的论点因为____。"
- ✓ **部分模型模板**——学生填写的结构化图，不是已完成图
- ✓ **词汇支持**——词库或简要词汇表
- ✓ **结构化观察表**："画出你看到的。标注任何变化。圈出意料之外的事。"
- ✓ **引导式数据表**——列标题和单位预填
- ✓ **前知识激活**——"记得我们以前学过的____吗？那可能怎样帮助解释你现在看到的？"

#### 脚手架密度上限：每个任务 1-2 个

### R5 — 必需的教学基础设施

| 部分 | 说明 |
|---|---|
| **形成性检测** | 具体提示——出门条或解释检查 |
| **锚点活动** | 选做题的课标延伸任务 |
| **灵活分组** | 基于本课证据，可在形成性检测后调整 |
| **各层常见错误** | 常见科学迷思 + 教师提示 |
| **认知冲突提示** | 显式呈现前概念与观察之间的张力 |

### R6 — 隐形调整

**相同现象、相同实验、相同核心解释任务。只有支持不同。**

### R7 — 层级内渐进式脚手架

#### 低层消退模式

| 任务 | 嵌入脚手架 |
|---|---|
| 观察任务 | 最多 2 个 |
| 表征任务 | 最多 1 个 |
| 解释/CER 任务 | 0-1 个 |
| 反思提示 | 0 个 |

#### 高层延伸质量

- 工程应用：用科学概念设计方案
- 反例：现象表现不同的情况
- 定量化：将定性解释与数学关系连接
- 前向标准预览：同一核心概念下一学段的要求
- 科学论证：评价竞争性解释
- 社会/伦理维度：与现实问题的连接

### R8 — 范围与默认值

**如果层级范围未指定：**
> "我将把这个课时分为低/中/高三个层级——这三个合适吗？有没有需要特别关注的学生需求？如果没有，我将应用通用设计默认值（所有三层提供句子支持和词汇支持）。"

### 文档内容——整合课时方案（`id: teacher_plan`）——最多 5 页

按阶段组织。还原源课时的阶段结构（导入现象→探究→讨论→解释任务→总结→出门条）。

```markdown
# 分层科学课时方案：[课时标题]

**核心概念：**[原文] **年级：**[X] **时长：**[X 分钟]
**驱动现象：**[一句话]
*学生需求：*

## 学习目标

## 三维目标
- **科学观念：**
- **科学思维：**
- **探究实践：**
- **态度责任：**
- **概念预备：** [支撑低层脚手架]
- **前向标准：** [支撑高层延伸]

## 层级分组

---
## [阶段名 — 全班]
## [阶段名 — 分层活动]
**全体学生：** [相同设置]

[表格：低层/中层/高层]

## 形成性检测

## 锚点活动

## 为什么有效 (1) / (2)

## 后续步骤
```

### 文档内容——练习单

无教师备注。所有三层包含：词汇表 + 句子支持 + 锚点活动 + 反思提示。

## 写 differentiation.json — 科学映射

- `shared.subject`: `"科学"`（或 `"物理"`/`"化学"`/`"生物"`）
- `shared.anchor_task`: 驱动现象
- `shared.t1`..`tN`: 所有三层共用的实验和解释任务

# 语文 — 分层教学法

Loaded by `k12-lesson-differentiation` when the subject is **ela**（语文）.

## 识别源课时

检测以下哪种场景：

**场景 A — 对话中已有源课时**
如果之前的对话中已产生或讨论过一个课时，直接使用它。不要重新请教师分享。

**场景 B — 教师上传源课时**
先读取文件。确认：年级、语文学习领域（识字写字/阅读/写作/口语交际/综合性学习）、课标要求、学习目标、课时结构。如果文件无法读取，清晰提示错误并请教师重新分享。不要凭空编造课时。

**场景 B2 — 教师通过 URL 提供源课时**
先获取 URL 并读取其内容。然后按场景 B 确认年级、语文领域、课标要求、学习目标、课时结构。如果获取失败或内容不可用，清晰提示错误并请教师粘贴文本或上传文件。

**完成场景 B/B2 仅完成第一步（识别课时），不代替标准锚定。** 继续到第二步——锚定课标。跳过第二步是与上传课时相同的关键性失败。

**场景 C — 无源课时**
在继续前询问：
> "没问题。你有具体的课要分层吗？可以粘贴内容、分享文件，或者告诉我年级 + 语文领域（识字/阅读/写作/口语交际）+ 课标要求，我来做。"

## 标准锚定

遵循 **SKILL.md 第二步——锚定课标**：使用 `references/curriculum/yuwen.md` 中的课标内容（核心素养、学习任务群、学段内容要求）作为标准的锚定来源。如果教师提供了地方性课程标准或校本标准，优先使用教师提供的标准。

**教材版本检测：** 检测教师是否提及教材版本（统编版/人教版/部编版）。如果已知，在输出中引用相应教材的单元编排逻辑。

## 分层规则

以下八条规则适用于每一个分层的课时。

### R1 — 输出结构

**1 份教师面向的分层方案 + 3 份纯粹的学生材料。绝不能是 3 份混合型的分层教案。**

混合型模式（每层一份含教师备注和学生任务的文档）是特定的失败模式。教师方案覆盖所有层级（一份文档）；学生材料仅面向学生，不含教师备注、观察要点或理由说明。

### R2 — 标准和范围保持

**每一层都面向原始课标要求。每个学习要素在所有层级中都要涉及——包括困难的部分。**

语文课时常交织多个语文要素——阅读理解、词汇、写作——在同一课时内。分层教学必须涉及每一个呈现的要素。不要为低层学生删减要素；代之以脚手架。

**必须保持低层的参与度。** 不要给中高层有趣的任务而给低层操练类工作。所有层级处理相同的文本和相同的基本问题——以不同的支持方式，而非不同的任务。

### R3 — 文本可及性：相同文本，不同脚手架

**所有三层使用相同的年级水平文本。文本复杂度不调整——调整的是对文本的访问方式。**

这是语文分层的核心原则。给低层学生更简单的文本会关闭年级水平的参与，而非培养参与。替换为：脚手架如何帮助学生访问年级水平文本。

三层对应从支持性访问到独立分析的递进：

| 层级 | 认知切入点 |
|---|---|
| 低层 | 支持性访问 → 有脚手架的生产。学生使用年级水平文本，通过分段阅读、预教词汇、注释引导和句子支持来完成任务。 |
| 中层 | 标准参与。学生按设计阅读年级水平文本并完成任务。 |
| 高层 | 独立分析/综合。学生阅读年级水平文本并超越检索，进入作者的写作技巧、评价、跨文本连接或创造性产出。 |

**对于写作课时：** 在各层保持相同的写作提示和写作目的。变化的是结构支持（框架、组织器、范例）。不要降低写作目的（例如，不要为低层学生将议论文改为摘要）。

### R4 — 低层脚手架

**脚手架支持思考但不揭示答案。使用句子支持、图形组织器、注释提示和词汇支持。绝不能是揭示答案的提示。绝不能是简化的内容替代品。**

需要避免的失败模式：

- ❌ 为低层学生替换为更简单的文本、段落或写作提示。这移除了年级水平的参与，不是脚手架。
- ❌ 当课标要求原本的形式时，降低写作目的（例如将议论文改为摘要，或多段落改为单句）。
- ❌ 预填的图形组织器，只留下空白填最终答案。
- ❌ 在学生阅读前告诉他们文本内容（揭示理解的前置阅读）。
- ❌ 回答任务的句子开头（"作者认为奴隶制是错误的，因为……"），而非结构化学生自己的思考（"作者认为______因为______"）。

可接受的脚手架：

- ✓ 分段阅读，配有引导性注释提示："阅读这段时标记：主要观点（圈出）、一个证据（下划线）、一个你不认识的词（？）"
- ✓ 词汇支持：3-5 个预教的关键术语，用学生友好的语言定义，在阅读和写作时可查阅。
- ✓ 结构化思考的句子支持，但不完成它："作者用______来表现______。"/"我的论点是______。一个理由是______。"
- ✓ 与语文任务匹配的图形组织器。
- ✓ 减少所需的文本例证数量——同时保持任务类型（例如，找 1 个例证而非 3 个，而不是切换为不同的任务类型）。

#### 语文任务 → 主要脚手架

| 语文任务类型 | 主要脚手架 |
|---|---|
| 阅读理解（叙事） | 故事图：角色/问题/事件顺序/结局 |
| 阅读理解（说明性/信息性） | 主要观点 + 证据组织器 |
| 议论文写作 | 论点-理由-证据框架 |
| 记叙文写作 | 故事主线或结构化故事图 |
| 说明文写作 | 思维导图 → 段落框架 |
| 文本分析（作者手法、结构） | 注释引导 + "作者用______来______" 框架 |
| 比较/对比（文本或角色） | T 形图或维恩图 |

#### 脚手架密度上限

**每个任务嵌入的脚手架上限为 1-2 个。**

| 类型 | 计入上限？ |
|---|---|
| 嵌入的——每个任务上印刷（组织器、句子支持、注释提示） | 是 |
| 页头级特征——页面顶部的词汇框、句子支持 | 否 |
| 教师侧支持——朗读许可、交谈提示、操作材料 | 否 |

**先选一个主要脚手架。** 只有当第二个脚手架贡献了真正不同的模式（例如视觉组织器 + 语言框架）时才添加。

测试标准：脚手架是否把思考工作留给了学生，还是替学生完成了思考？如果是后者，那就不是脚手架。

### R5 — 必需的教学基础设施

**每个分层课时必须包含所有四项：**

| 部分 | 说明 | 位置 |
|---|---|---|
| **形成性检测** | 课中或课末的具体检测提示——分层的"出门条"属于此类。不是"观察学生"。 | 教师方案 + 各层学生材料 |
| **锚点活动** | 面向课标要求的选做题。非填充时间。应连接本课的语言要素（如独立阅读、写话延伸）。以学生可读形式写入 `shared.anchor_activity`，印在每份学生材料上——仅存在于方案描述中的锚点活动是失败。 | 教师方案 + 三层学生材料 |
| **灵活分组语言** | 层级分配基于**本课**的证据，明确说明可根据形成性检测结果调整。非静态阅读能力分组。 | 教师方案 |
| **各层常见错误/常见错误** | 各层常见的阅读理解或写作错误 + 教师提示 + 小组辅导信号。 | 教师方案 |

此外：**每份学生材料以一个反思提示结尾，三层相同**——例如"你认为作者的主要目的是什么？从文中找出依据。"/"你写作中最困难的部分是什么？你会怎么改？"这不是任何一层的可选内容。存入 `shared.reflect_prompt`，在教师方案的各层任务行中引用它。

### R6 — 隐形调整

**在可能的情况下，所有层级使用相同的文本/相同的提示/相同的核心任务。只有支持不同。**

可以不同：学生材料中嵌入的脚手架；教师交谈时的可选支持；延伸或反思提示的深度。

不应不同：学生阅读的文本；写作目的或提示；课标针对的结构性挑战；主题或情境。

**不要向学生宣布脚手架的移除。** 如果脚手架出现在任务 1 但不在任务 3，它的缺席是隐形的——没有标签、旁注或评论（例如不要写"这次没有组织器"或"试试不用框架"）。脚手架简单不出现；学生以自己的方式面对任务。

### R7 — 层级内渐进式脚手架

**每层的学生材料按认知递进排列任务。**

#### 低层消退模式

| 任务 | 嵌入脚手架 | 模式 |
|---|---|---|
| 任务 1 | 最多 2 个 | 有脚手架 |
| 任务 2 | 最多 1 个 | 引导式 |
| 任务 3+ | 0 个嵌入 | 独立 |
| 出门条 | 0-1 个 | 掌握检测 |

目标是真正的消退（2→1→0），而非所有任务统一密度的装饰性变化。

#### 高层延伸质量测试

每个高层延伸必须回答：**这需要什么样的新思考，而中层学生尚未在做？**

真正的延伸需要至少一种：

| 类型 | 要求 |
|---|---|
| 作者手法分析 | 从"文本说了什么"到"作者为什么做这个选择，产生了什么效果" |
| 视角转换 | 从另一角色的视角复述；为相反论点辩护；以不同修辞目的重写 |
| 跨文本综合 | 连接第二文本，比较论点、结构、作者视角或主题 |
| 结构洞察 | 关于体裁、结构或作者策略的概括，中层任务将其作为单一实例处理 |
| 开放生成任务 | 学生产出新内容：模仿作者风格的原创作品、反论点、课堂讨论的问题 |

拒绝如果：更多同类、符号/词汇替换、或重述。

### R8 — 范围与默认值

**如果层级范围未指定，先问一个合并问题：**

> "我将把这个课时分为低/中/高三个层级——这三个合适吗？有没有需要特别关注的学生需求（如随班就读、少数民族双语学生）？如果没有，我将应用通用设计默认值（所有三层都提供句子支持和词汇表）。"

**未指定时的默认值：**
- 层级：低层/中层/高层
- 通用设计特征：句子支持和词汇表在**所有三层**学生材料中（不仅是低层）
- 范围：完整课时（所有阶段 + 出门条）
- 文本：所有层级使用相同的年级水平文本（从不替换）

**缺乏学情数据时的默认低层画像：**

当没有诊断数据时，按学段设计最可能的画像：

- **小学 1-2 年级：** 识字量不足是主要瓶颈。拼音/识字支持优先。朗读作为可选的教师侧支持。
- **小学 3-6 年级：** 默认画像为阅读流畅性遇到瓶颈——识字准确率足够但自动化程度低，占用工作记忆并降低理解。优先使用流畅性支持结构（朗读许可、伙伴阅读）与理解脚手架并重。词汇预教是第二个杠杆。
- **初中 7-9 年级：** 默认画像为词汇和背景知识不足。学术词汇是常见的瓶颈。先搭建语义和句法脚手架。
- **高中 10-12 年级：** 默认画像为背景知识和分析策略不足。先搭建推理性理解框架。

**生成分层方案后，向教师确认学情：**

> "你有没有最近的学生阅读数据——听写成绩、阅读测试结果或写话样本——可以帮助我更精准地定位脚手架？甚至非正式记录学生在哪一步卡住了也有帮助。"

不把学情确认作为可选步骤。默认的分层方案是初步的最佳推测；有数据时的调整可以显著改变脚手架策略。

### 文档内容——教师方案（`id: teacher_plan`）——最多 3 页

**字数预算：实际渲染约 1200 字。** 在触及结尾部分（灵活分组、为什么有效、后续步骤）之前，先收紧层级部分和概览——最常见的超限是任务行重述学生材料内容而非命名。

以下大纲定义教师方案文档 `sections` 的内容和顺序：

```markdown
# 分层方案：[课时标题]

**课标要求：**[原文] **年级：**[X] **领域：**[识字/阅读/写作/口语交际/综合性学习] **时长：**[X 分钟]
*学生需求：[如果未提供: "应用通用设计默认值——所有三层提供句子支持和词汇支持。" 如果提供了学生需求，在此描述。]*

## 学习目标
[所有三层同一目标——保持源课时不变]

## 分层概览
[1 短段，≤3 句：方法、文本确认所有三层共用、预备知识描述、前向标准描述。绝不在此处粘贴完整课标文本——目标标准已在页头引用。]

## 层级设计
[一个 `table` 块——绝不是三段独立段落。列：低层(A组) / 中层(B组) / 高层(C组)。
行（某行可能用"—"表示对该层不适用）：
- **锚定标准**——低层：预备知识概念 + 说明。高层：前向标准 + 说明。中层："—"。
- **脚手架/延伸**——简短，≤25 字每格：低层脚手架；中层支持；高层延伸 + 符合哪种 R7 质量类型。
- **交谈提示**——每层一个具体的教师提示。
- **学生材料任务**——≤40 字每格，最后写：从头到尾读那份材料的 blocks，按顺序命名每个印刷任务及其脚手架]

[一个 `callout`（注意风格）：常见错误/常见错误——模式 + 教师提示，每层 ≤2 句]

## 形成性检测
[两个必需元素：
1. **课中检查点：** 阅读或写作中的具体检查——命名触发条件或产出物。'巡视观察'不算。
2. **出门条（含明确分类标准）：** 学生必须产出或展示什么以落在每个分类中。无课时特定指标的通用分类标签不算。]

## 锚点活动
[`from_shared: anchor_activity`——印在每份学生材料上的面向学生的相同任务 + 一行教师说明]

## 灵活分组
[当前层级分配、依据的学情证据、以及明确声明分组可在形成性检测后调整]

## 为什么有效 (1)
[一个具体的层级设计选择 + 理由]

## 为什么有效 (2)
[第二个具体的层级设计选择 + 理由]

## 后续步骤
**已掌握（出门条通过）：** [连接前向标准或下一课]
**接近掌握：** [针对性小组或交谈]
**需补习：** [具体补习策略或需额外支持]

```

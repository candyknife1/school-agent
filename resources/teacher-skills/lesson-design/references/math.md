# 数学 — 分层教学法

Loaded by `k12-lesson-differentiation` when the subject is **math**（数学）.

## 识别源课时

检测以下哪种场景：

**场景 A — 对话中已有源课时**
如果之前的对话中已产生或讨论过一个课时，直接使用它。不要重新请教师分享。

**场景 B — 教师上传源课时**
先读取文件。确认：年级、数学领域（数与代数/图形与几何/统计与概率/综合与实践）、课标要求、学习目标、课时结构。如果文件无法读取，清晰提示错误并请教师重新分享。

**场景 B2 — 教师通过 URL 提供源课时**
先获取 URL 并读取其内容。然后按场景 B 确认年级、领域、课标要求、学习目标、课时结构。如果获取失败，清晰提示并请教师粘贴或上传。

**完成场景 B/B2 仅完成第一步（识别课时），不代替标准锚定。** 继续到第二步——锚定课标。

**场景 C — 无源课时**
在继续前询问：
> "没问题。你有具体的课要分层吗？可以粘贴内容、分享文件，或者告诉我年级 + 数学领域 + 课标要求，我来做。"

## 标准锚定

遵循 **SKILL.md 第二步——锚定课标**：使用 `references/curriculum/math.md` 中的课标内容（核心素养、内容要求、学业质量）作为标准锚定来源。如果教师提供了地方课程纲要或校本标准，优先使用。

**教材版本检测：** 检测教师是否提及教材版本（人教版/北师大版/苏教版/华师大版等）。如果已知，在输出中引用相应教材的单元编排与例题结构。

## 分层规则

应用以下八条规则到每一个分层的课时。

### R1 — 输出结构

**1 份教师面向的分层方案 + 3 份纯粹的学生练习单。绝不能是 3 份混合型的分层教案。**

混合型模式是特定的失败模式。教师方案覆盖所有层级（一份文档）；练习单仅面向学生。

### R2 — 标准范围保持

**每一层都面向原始的课标要求。每个标准要素在所有层级中都要涉及——包括困难的部分。**

课标中最困难的案例正是低层学生最需要以脚手架方式接触的内容，而不是要舍弃的内容。降低低层学生的认知范围不是分层。

**必须保持低层的参与度。** 不要给中高层有趣的现实情境题而给低层程序性操练。相同的情境，相同的导入——以不同的支持方式。

### R3 — 通过命名预备知识实现"教上去"

**低层脚手架将学生向上引导到年级水平的工作，基于一个命名的预备知识。而不是"只是更简单的题"。**

- ✓ "低层使用[视觉模型]来呈现[某一概念]（来自[前一学段]）；学生应用该表示到年级水平的问题。"
- ✗ "低层使用更简单的数/更短的文字/更少的步骤。"

#### CRA 切入点

| 层级 | CRA 切入点 |
|---|---|
| 低层 | 具象（学具或实物模型）→ 表象（图示、视觉模型） |
| 中层 | 表象 → 抽象（符号化、数字化） |
| 高层 | 抽象 → 联系（概括、结构洞察、前向标准） |

### R4 — 低层脚手架

**脚手架支持思考但不揭示答案。绝不能是揭示答案的提示。绝不能是关键词策略。**

失败模式：
- ❌ 关键词策略（"看到'一共'就是要合并"）——破坏测试意图
- ❌ 在概念理解之前预教算法
- ❌ 预填模板只留答案空白
- ❌ 原始任务要求开放产出时使用选择题

可接受的脚手架：
- ✓ 句子支持："我知道____和____。我不知道的部分是____。"
- ✓ 与数学概念匹配的视觉组织器
- ✓ 学具或具象提示，连接抽象任务（按 CRA）
- ✓ 词汇表（非用于选择答案）
- ✓ 降低复杂度并明确转移步骤："先用这个试试，再应用到原题。"

#### 概念 → 主要视觉模型

| 数学概念类型 | 主要视觉模型 |
|---|---|
| 部分-整体 / 加法推理 | 线段图或部分-整体图 |
| 乘法 / 比 / 比例推理 | 双数线或比例表 |
| 作为数轴上的量的分数 | 数轴 |
| 面积 / 乘法结构 | 面积模型或阵列 |
| 比例关系 / 线性函数 | 数值表或坐标图 |
| 代数结构 / 方程推理 | 方程平衡模型或变量表示 |
| 几何关系 | 标注图，带注释 |

#### 脚手架密度上限

**每个问题嵌入的脚手架上限为 1-2 个。** 先选一个主要脚手架。

### R5 — 必需的教学基础设施

**每个分层课时必须包含所有四项：**

| 部分 | 说明 | 位置 |
|---|---|---|
| **形成性检测** | 分层的出门条或课中提示。不是"观察学生"。 | 教师方案 + 各层练习单 |
| **锚点活动** | 面向课标要求的选做题。以学生可读形式写入 `shared.anchor_activity`，印在每份练习单上。 | 教师方案 + 三层练习单 |
| **灵活分组语言** | 基于本课证据的分组，明确可在形成性检测后调整。 | 教师方案 |
| **各层常见错误** | 错误模式 + 教师提示 + 小组辅导信号。 | 教师方案 |

**每份练习单以一个反思提示结尾，三层相同。** 存入 `shared.reflect_prompt`。

### R6 — 隐形调整

**相同情境/相同背景/相同核心问题。只有支持不同。**

可以不同：练习单上的脚手架；教师交谈时的支持；延伸提示深度。

不应不同：问题背景；核心问题；课标针对的结构性挑战。

**不要向学生宣布脚手架的移除。**

### R7 — 层级内渐进式支持

**每份练习单按认知递进排列问题。**

#### 低层消退模式

| 问题 | 嵌入脚手架 | 模式 |
|---|---|---|
| 问题 1 | 最多 2 个 | 有脚手架 |
| 问题 2 | 最多 1 个 | 引导式 |
| 问题 3+ | 0 个嵌入 | 独立 |
| 出门条 | 0-1 个 | 掌握检测 |

#### 高层延伸质量测试

每个高层延伸必须回答：**这需要什么样的新思考，而中层学生尚未在做？**

| 类型 | 要求 |
|---|---|
| 新认知操作 | 中层应用；高层分析、评价或创造（布鲁姆/DOK 移位） |
| 结构洞察 | 概括、等价或逆关系，中层将其作为单一实例处理 |
| 前向标准预览 | 来自高一年级课标的真实概念元素 |
| 开放生成任务 | 学生编题、设计反例或从头构建论证 |

### R8 — 范围与默认值

**如果层级范围未指定，先问一个合并问题：**

> "我将把这个课时分为低/中/高三个层级——这三个合适吗？有没有需要特别关注的学生需求？如果没有，我将应用通用设计默认值（所有三层提供句子框架和词汇支持）。"

**未指定时的默认值：**
- 层级：低层/中层/高层
- 通用设计：句子框架和词汇表在所有三层练习单中
- 范围：完整课时（含出门条）

**学情跟进提示——在生成了默认方案后询问：**

> "你有没有最近的门条结果、诊断分数或关于学生卡在哪里的观察笔记——例如，他们理解了概念但丢了步骤，还是对概念本身含义感到困惑？"

### 文档内容——教师方案（`id: teacher_plan`）——最多 3 页

```markdown
# 分层方案：[课时标题]

**课标要求：**[原文] **年级：**[X] **时长：**[X 分钟] **教材：**[人教版/北师大版/苏教版/通用]
*学生需求：[如果未提供: "应用通用设计默认值"]*

## 学习目标
[所有三层同一目标]

## 分层概览
[1 短段，≤3 句：方法、预备知识 + 说明、前向标准 + 说明。不粘贴完整课标文本]

## 层级设计
[一个 `table` 块——列：低层(A组) / 中层(B组) / 高层(C组)]

[一个 `callout`：常见错误/常见错误]

## 形成性检测
[课中检查点 + 出门条含明确分类标准]

## 锚点活动
[`from_shared: anchor_activity`]

## 灵活分组

## 为什么有效 (1) / (2)

## 后续步骤
**已掌握：** **接近掌握：** **需补习：**
```

### 文档内容——练习单（`id: worksheet_group_a` / `b` / `c`）

无教师备注。所有三层包含：词汇表 + 句子框架 + 锚点活动 + 反思提示——均从 `shared` 拉取。

```markdown
# [A组 / B组 / C组] — [课时标题]

**姓名：** _________________ **日期：** _________

## 词汇
[`from_shared: vocabulary`]

**你可以使用这些句子支持：**
- "我知道____和____。我不知道的部分是____。"
- "我的策略是______因为______。"

---
[问题逐一取出，每个问题上方直接放置脚手架]
---

## 选做题
[`from_shared: anchor_activity`]

## 反思
[`from_shared: reflect_prompt`]
```

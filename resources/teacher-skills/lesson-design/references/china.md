# 中国基础教育语境锚点（k12-lesson-planning）

本文件提供中国 K-12（义务教育 + 普通高中；中职可参照）的学科映射、标准锚点、教学范式与产出模板，使教案规划技能默认按中国课堂运行。

> 📚 **2022 版课程标准已嵌入**：详细的核心素养、内容要求、学业质量见 `references/curriculum/` 各科文件。

## 一、学段与年级映射

| 中国学段 | 年级 | 备注 |
|----------|------|------|
| 小学低年级 | 1–2 | 课时一般 40 分钟 |
| 小学中高年级 | 3–6 | 课时一般 40 分钟 |
| 初中（七年级–九年级） | 7–9 | 课时一般 40–45 分钟 |
| 高中（十年级–十二年级） | 10–12 | 课时一般 45 分钟 |
| 中职（可参照） | 对应学段 | 以"学科核心素养 + 1+X 职业技能等级"双锚点 |

> 美国学段代号 K-2 / 3-5 / 6-8 / 9-12 在中文语境下分别对应：1-2 年级 / 3-6 年级 / 7-9 年级 / 10-12 年级。

## 三、课程标准依据（优先级从高到低）

1. **国家课程方案**：《义务教育课程方案（2022 年版）》《普通高中课程方案（2017 年版 2020 年修订）》。
2. **各学科课程标准**：义务教育各科课标（2022）、普通高中各科课标；以"**学科核心素养**"与"**学业质量水平**"为设计锚点。
3. **教材版本**：教师指定的版本（人教版 / 北师大版 / 苏教版 / 华东师大版 / 鲁科版 等）的话语与结构。
4. **地方/校本**：地方教研要求、学校人才培养方案（中职含 1+X 证书标准）。

**无标准库连接时**：从本文件与通用最佳实践生成，并在教案页脚标注（见 §六 脚注）。

## 四、教学范式（默认采用）

- **核心素养导向**：目标表述落到学科核心素养，而非仅知识点罗列。
- **教学评一体化**：教学目标、学习活动、评价任务一致；出口票/课堂小测即评价环节。
- **大单元教学**：以素养为导向组织大主题/大任务，课时作为单元内的节点。
- **项目式学习（PBL）/ 情境教学**：应用级以上任务嵌入真实生活或职业情境。
- **跨学科主题学习**：义务教育要求各学科不少于 10% 课时用于跨学科主题学习。
- **课程思政**：价值引领（政治认同、家国情怀、工匠精神、科学态度）自然融入，不另贴标签、不空洞说教。

## 五、教学环节模板（本土化）

默认采用"五环节"骨架，按学段与课型弹性调整；每个环节的分钟数之和必须精确等于课时（40–45 分钟），转场时间计入环节内：

| 环节 | 作用 | 建议占比 |
|------|------|----------|
| 导入（情境/复习引新） | 激发、铺垫 | 5–8 分钟 |
| 新授（探究/讲授/合作） | 核心建构 | 15–20 分钟 |
| 巩固/练习（学以致用） | 迁移、诊断 | 8–12 分钟 |
| 小结（提炼/板书建构） | 归纳、升华 | 3–5 分钟 |
| 作业（分层布置） | 延伸、评价 | 2–3 分钟（含布置） |

> 理科可改用"提出问题—实验探究—分析论证—应用迁移—小结作业"；文科可改用"初读感知—精读品析—合作探究—拓展表达—小结作业"。

## 六、作业与减负（"双减"）

- 小学一、二年级**不布置家庭书面作业**；其他年级控制总量。
- 作业分三层：**基础型**（保底）、**拓展型**（迁移）、**弹性/探究型**（选做）；与分层教学呼应。
- 出口票/课堂小测优先作为**课内**形成性评价，减少课外负担。

# 义务教育化学课程标准（2022年版）

依据：教育部教材〔2022〕2号 | PDF: `raw/curriculum-2022/10-化学.pdf`

**核心素养**：化学观念、科学思维、科学探究与实践、科学态度与责任

**内容五大主题**：
1. 科学探究与化学实验
2. 物质的性质与应用
3. 物质的组成与结构
4. 物质的化学变化
5. 化学与社会·跨学科实践

**学段**：九年级开设

# 义务教育生物学课程标准（2022年版）

依据：教育部教材〔2022〕2号 | PDF: `raw/curriculum-2022/11-生物学.pdf`

**核心素养**：生命观念、科学思维、探究实践、态度责任

**内容七大主题**：
1. 生物体的结构层次
2. 生物的多样性
3. 生物与环境
4. 植物的生活
5. 人体生理与健康
6. 遗传与进化
7. 生物学与社会·跨学科实践

**学段**：七年级和八年级开设

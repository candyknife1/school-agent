# 义务教育信息科技课程标准（2022年版）

依据：教育部教材〔2022〕2号 | PDF: `raw/curriculum-2022/12-信息科技.pdf`

## 核心素养（4个方面）

| 核心素养 | 内涵 |
|---------|------|
| **信息意识** | 对信息的敏感度和对信息价值的判断力，信息安全意识 |
| **计算思维** | 运用计算机科学原理和方法解决问题的思维模式 |
| **数字化学习与创新** | 利用数字平台和工具进行高效学习与创新创造 |
| **信息社会责任** | 在信息社会中遵守法律法规，恪守伦理规范 |

## 课程内容（分学段）

| 学段 | 年级 | 内容重点 |
|------|------|---------|
| 第一学段 | 3-4年级 | 信息交流、数字作品创作、在线安全 |
| 第二学段 | 5-6年级 | 数据组织、算法初步、编程基础（Scratch/Python） |
| 第三学段 | 7年级 | 互联网原理与应用、数据处理 |
| 第四学段 | 8年级 | 物联网、人工智能初步 |
| 第五学段 | 9年级 | 人工智能基础、未来社会 |

# 义务教育体育与健康课程标准（2022年版）

依据：教育部教材〔2022〕2号 | PDF: `raw/curriculum-2022/15-体育与健康.pdf`

## 核心素养（3个方面）

| 核心素养 | 内涵 |
|---------|------|
| **运动能力** | 基本运动技能、专项运动技能、体能水平 |
| **健康行为** | 自主锻炼习惯、健康生活方式、安全意识 |
| **体育品德** | 体育精神、规则意识、公平竞争、团队合作 |

## 课程内容
1. 基本运动技能（1-2年级）：移动、操控、稳定
2. 体能（各学段）：力量、速度、耐力、柔韧、灵敏
3. 专项运动技能：球类、田径、体操、游泳、冰雪、中华传统体育、新兴体育
4. 健康教育：健康知识、疾病预防、安全应急与避险

## 课时
1-9年级每周4课时

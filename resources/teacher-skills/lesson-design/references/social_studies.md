# 史地政（道德与法治/历史/地理） — 分层教学法

Loaded by `k12-lesson-differentiation` when the subject is **social studies**（道德与法治/历史/地理）.

## 识别源课时

**学科识别。** 检测教师涉及的学科方向：道德与法治（包括国情/法律/品德教育）、历史（中外通史/专题史）、地理（自然地理/人文地理/区域地理）。可以根据教师的表述或上传的材料来判定。

**场景 A — 对话中已有源课时**
直接使用。不要重新请教师分享。

**场景 B — 教师上传源课时**
先读取文件。确认：年级、学科方向（道德与法治/历史/地理）、课标要求、学习目标、课时结构。如果无法读取，清晰提示并请教师重新分享。

**场景 B2 — 教师通过 URL 提供源课时**
先获取 URL 并读取其内容。确认后按场景 B 处理。

**完成场景 B/B2 仅完成第一步，不代替标准锚定。**

**场景 C — 无源课时**
> "没问题。你有的具体课要分层吗？可以粘贴内容、分享文件，或者告诉我年级 + 学科（道法/历史/地理）+ 课标要求，我来做。"

## 分层规则

应用以下八条规则到每一个分层的课时。

### R1 — 输出结构

**1 份教师面向的分层方案 + 3 份纯粹的学生练习单。**

### R2 — 标准范围保持

**每一层都面向原始的课标要求。每个标准要素在所有层级中都要涉及——包括困难的部分。**

常见失败模式：
- ❌ 为低层学生将比较佐证任务替换为单一来源任务——这不是分层，是不同的作业。
- ❌ 从低层工作中移除核心探究问题。
- ❌ 为低层学生用识别代替论证。

**必须保持低层的参与度。**

### R3 — 通过预备知识实现"教上去"

**低层脚手架将学生向上引导到年级水平的工作。不是"更简单"。**

#### 两个主要预备知识

1. **内容词汇。** 访问课时的来源材料和任务所需的具体术语是最主要的关口。提取 4-6 个与来源材料直接相关的关键术语——这些成为词库。词汇是预备知识关卡，而不仅仅是通用设计特征。

2. **史料/信息来源分析作为教过的方法。** 信息来源分析（谁制作的、为什么、在什么条件下？）是基础性的学科思维方法——它是情境化和佐证的前提。将它作为教过的方法处理，而非假设的能力。如果教师确认信息来源分析已是课堂常规做法，则将低层脚手架转向情境化支持。

#### 来源复杂度切入点（按学科调整）

| 层级 | 切入点 |
|---|---|
| 低层 | 具象/视觉——照片、地图、实物或带注释的简短节选；1 个来源；有脚手架的分析框架 |
| 中层 | 表象/文本——适当文本或轻度注释来源；1-2 个来源；结构化问题 |
| 高层 | 抽象/论证——完整来源或复杂二级文本；2-3 个来源；开放综合或论证任务 |

### R4 — 低层脚手架

**目标是保护产生性挣扎——脚手架支持思考但不揭示答案或折叠历史/公民推理。**

失败模式：
- ❌ 单一原因简化
- ❌ 答案嵌入问题
- ❌ 填空叙述
- ❌ 用现代价值观简化历史情境

可接受的脚手架：
- ✓ 句子支持
- ✓ 引导式分析框架（适合中国学情：如"五要素分析法"——时/地/人/事/因）
- ✓ 分层的文本：相同主题和核心问题，不同阅读复杂度；所有层相同问题
- ✓ 视觉来源（照片、地图）作为具象切入点
- ✓ 学科特定词汇的词库
- ✓ 与思考类型匹配的图形组织器
- ✓ 减少来源数量并明确转移步骤

#### 学科思维 → 主要脚手架

| 史地政思维类型 | 主要脚手架 |
|---|---|
| 时序推理/顺序 | 标注时间线或因果链组织器 |
| 史料分析 | 引导式分析框架 |
| 地理/空间推理 | 标注地图 + 结构化引导问题 |
| 公民论证/论点推理 | 论点-证据-推理框架 |
| 经济决策/权衡 | 成本-收益或稀缺性组织器 |
| 多视角/观点 | 双栏视角组织器 |
| 比较/综合 | T 形图或证据综合矩阵 |

#### 脚手架密度上限：每个任务 1-2 个

### R5 — 必需的教学基础设施

| 部分 | 说明 |
|---|---|
| **形成性检测** | 课中或课末具体检测——分层的出门条 |
| **锚点活动** | 选做题的课标延伸任务，印在每份练习单上 |
| **灵活分组** | 基于本课证据，可在形成性检测后调整 |
| **各层常见错误** | 常见学科错误 + 教师提示 |

**每份练习单以反思提示结尾，三层相同。** 存入 `shared.reflect_prompt`。

### R6 — 隐形调整

**相同核心问题/相同来源情境/相同核心任务。只有支持不同。**

可以不同：文本阅读复杂度；脚手架；教师交谈支持；延伸提示。

不应不同：探究的核心问题；所需的学科思维类型；研究的历史/地理/公民现象。

### R7 — 层级内渐进式脚手架

#### 低层消退模式

| 任务 | 嵌入脚手架 |
|---|---|
| 任务 1 | 最多 2 个 |
| 任务 2 | 最多 1 个 |
| 任务 3+ | 0 个嵌入 |
| 出门条 | 0-1 个 |

#### 高层延伸质量

- 新认知操作：中层来源/描述；高层佐证、评价或构建论证
- 学科洞察：史学争鸣、解释张力或方法论问题
- 前向标准预览
- 开放生成任务：历史论证、反论点、公民提案

### R8 — 范围与默认值

**如果层级范围未指定：**
> "我将把这个课时分为低/中/高三个层级——这三个合适吗？有没有需要特别关注的学生需求？如果没有，我将应用通用设计默认值（所有三层提供句子框架和词汇支持）。"

### 文档内容——教师方案（`id: teacher_plan`）——最多 3 页

```markdown
# 分层方案：[课时标题]

**课标要求：**[原文] **年级：**[X] **学科：**[道德与法治/历史/地理] **时长：**[X 分钟]
*学生需求：*

## 学习目标

## 分层概览

## 层级设计
[表格：低层/中层/高层]

[一个 `callout`：常见错误/常见错误]

## 形成性检测

## 锚点活动

## 灵活分组

## 为什么有效 (1) / (2)

## 后续步骤
**已掌握：** **接近掌握：** **需补习：**
```

### 文档内容——练习单（`id: worksheet_group_a` / `b` / `c`）

无教师备注。所有三层包含：词汇表 + 句子支持 + 锚点活动 + 反思提示。

## 写 differentiation.json — 史地政映射

- `shared.subject`: `"道德与法治"` / `"历史"` / `"地理"`
- `shared.anchor_task`: 核心探究问题
- `shared.t1`..`tN`: 所有三层共用的来源分析任务
- 教师文档：分层方案，最多 3 页；练习单最多 2 页各

# 学习支架设计深度指南

> 本指南用于教师在第四步"规划项目活动与任务链"中，将支架从"任务布置"做到"真正支撑思考"。支架是 PBL 设计中最容易被简化的环节，也是诊断中权重最高的维度（30%）。

---

## 一、核心区分：支架 ≠ 任务布置

| | 任务布置（Task Assignment） | 学习支架（Learning Scaffold） |
|---|---|---|
| 本质 | 告诉学生"做什么" | 帮助学生"怎么想、怎么做" |
| 学生体验 | "按要求完成作业" | "有人帮我拆解困难、示范路径" |
| 典型特征 | 只给指令和截止时间 | 嵌入思维引导、示范、阶梯式支持 |
| 例子 | "请完成 KWL 表格并提交" | KWL 表格中预填了 2 个示例问题，W 栏附了"你还可以这样问……"的句式提示 |

> **判断铁律**：把支架拿掉，学生还能不能完成这个任务？如果答案是"能"——那你设计的不是支架，只是多了一道流程。

---

## 二、支架设计三原则

1. **思维可视化**：把"专家是怎么思考的"展示给学生，而不是只告诉学生"要思考"
2. **阶梯递进**：支架内自带由易到难的层次，不同水平的学生都能找到入口
3. **可撤除性**：支架是临时工具——项目初期有，中后期逐步撤除，学生最终能脱离支架独立完成

---

## 三、五类支架的"弱版 vs 强版"对照

### 思维支架（Thinking Scaffolds）

思维支架的核心是帮助学生组织、可视化自己的思考过程，而不是替他们想好答案。

| 弱版（像任务布置） | 强版（真正支撑思考） | 强在哪 |
|---|---|---|
| KWL 表格：三列空白，标题 K/W/L | KWL 表格：K 栏预填一个示例"课堂上我们学过……"；W 栏附 3 个句式模板——"如果……会怎样？""……和……有什么关系？""为什么……会……？" | 预置思维触发点，减少"不知道写什么"的空白恐惧 |
| 概念图模板：空白方框 + 连线 | 概念图模板：部分核心概念已放入方框，学生补充剩余概念和所有关系线，并在每条线上标注关系类型（因果/并列/从属） | 给框架不给空架子——学生仍要思考关系，但不必从零搭建 |
| 比较表：左右两列，表头空白 | 比较表：表头已填"相同点""不同点"，左侧附了一个完成示例行，右侧附提示"还能从哪些角度比较？" | 示范比较维度，同时留出扩展空间 |

### 过程支架（Process Scaffolds）

过程支架帮助学生走通一个不熟悉的流程，核心是**预判困难并提前给出支持路径**。

| 弱版（像任务布置） | 强版（真正支撑思考） | 强在哪 |
|---|---|---|
| 实验记录表：步骤 1/2/3，空白待填 | 实验记录表：每步旁附"⚡ 注意"提醒框——"这一步最容易出错的是……"；末尾附"如果结果和预期不一致，可能的三个原因……" | 预判典型困难，避免学生卡住后放弃 |
| 原型迭代记录表：版本 1/2/3，空白 | 原型迭代记录表：每个版本后附三段引导——"上一版的问题 → 这一版的改进 → 为什么这样改"。第一行已填示例 | 把"迭代思维"变成可模仿的结构 |
| 资料分析任务："阅读以下三篇材料并分析" | 资料分析任务配"分析导航卡"：每篇材料旁标——"这篇帮你回答哪个子问题？""材料中哪句话最有力？""有没有需要怀疑的信息？" | 不是"读材料"，而是"带着问题读" |

### 信息支架（Information Scaffolds）

信息支架不是替学生找答案，而是帮学生**高效获取和筛选信息**——减少低效搜索，示范信息素养。

| 弱版（像任务布置） | 强版（真正支撑思考） | 强在哪 |
|---|---|---|
| "请上网搜索相关资料" | 提供 5 篇精选文献列表，每篇附 1 句话引导——"这篇能帮你回答哪个子问题？为什么这篇值得读？" | 缩小搜索范围，示范"有目的地检索" |
| 阅读材料直接下发给学生 | 每篇阅读配"阅读导航"：核心问题 → 关键段落标注 → 读后自检——"用一句话概括这篇的主要观点" | 不是"读完就行"，而是"读完后你知道了什么" |
| 专家讲座（讲完即走） | 专家讲座前发"讲座引导单"——"听完后你需要回答的三个问题"；讲座后留 5 分钟学生提问 | 把被动听讲变成主动获取 |

### 协作支架（Collaboration Scaffolds）

协作支架不只需要分配角色，更需要**教学生怎么合作**——怎么讨论、怎么给反馈、怎么解决分歧。

| 弱版（像任务布置） | 强版（真正支撑思考） | 强在哪 |
|---|---|---|
| 角色卡：项目经理 / 记录员 / 发言人，只写了角色名称 | 角色卡：每个角色附三项——"你的具体任务""你需要和谁配合""当你不知道怎么办时可以先……" | 不只分配角色，还示范角色行为 |
| 同伴反馈表：打分 + 写评语 | 同伴反馈表：表旁附"反馈句式卡"——"我注意到你……""如果……会不会更好？""我有一个疑问：……" | 学生不是天然会反馈——需要句式示范 |
| 小组讨论："各组交流一下" | 小组讨论配"讨论启动卡"：每人抽一张——"我同意 XX 的观点，因为……""我有不同的想法：……""我有一个证据支持 XX……" | 避免"有人沉默、有人包场" |

### 元认知支架（Metacognitive Scaffolds）

元认知支架帮助学生**觉察自己的学习过程**，而不只是总结学到的知识。

| 弱版（像任务布置） | 强版（真正支撑思考） | 强在哪 |
|---|---|---|
| "写一篇学习反思" | 反思写作框架："今天我学了……我是通过……学会的。过程中我遇到……我通过……克服了。下次我会……因为……" | 给结构，不给白纸 |
| 项目复盘：小组口头讨论 | 复盘讨论卡：每人抽 1 张启动句——"我们组做得最好的是……因为……""如果重来一次，我会……""我从 XX 身上学到了……" | 避免"没什么好说的"的沉默 |
| 终期反思表："你学到了什么？" | 三栏反思表："我最初以为……→ 探究后发现……→ 现在我认为……"。附一例示范行 | 展示"观念转变"的过程，而非只收结果 |

## 四、分层支架设计法

同一个活动，不同学生需要不同强度的支架。一个支架可以内置三层，让学生自选进入：

| 支架强度 | 形式 | 适用学生 | 举例（以"实验设计"为例） |
|---|---|---|---|
| 轻 | 仅口头提示："想想我们之前学过的实验设计步骤" | 已有经验、能独立推进的学生 | 发放空白实验设计表格 |
| 中 | 半结构化模板（关键节点预填，其余留白） | 需要方向但不需要手把手的学生 | 实验设计表：研究问题和变量已标注，步骤由学生填写 |
| 强 | 完整范例 + 模仿路径 + 分步拆解 + 每一步的引导问题 | 初次接触该任务类型的学生 | 实验设计表：每栏附引导问题 + 提供了一个化学实验的完整范例供参照 |

> **设计诀窍**：同一张工作纸，左边是"基础版"（完整引导），右边翻过来是"挑战版"（仅提示）——让不同起点的学生都能进入，而不是把学生按能力分成不同组发不同的纸。

## 五、支架自查清单

完成支架设计后，拿以下 5 个问题逐项自查：

- [ ] **拿掉支架试**：如果把这个支架撤掉，学生在哪个环节会卡住？——如果答案是没有，这不是支架
- [ ] **思维可见试**：学生拿到这个支架，能否看到"别人是怎么思考和解决的"？——如果看不到，只有指令
- [ ] **分层入口试**：同一个活动中，不同水平的学生是否都能找到自己可以启动的入口？——如果不能，没有分层
- [ ] **撤除路径试**：项目进程中，这个支架什么时候可以弱化或撤除？——如果没有计划撤除，会变成拐杖
- [ ] **类型覆盖试**：全项目是否至少覆盖了 3 种不同类型的支架（思维/过程/信息/协作/元认知）？——如果只有一种，太单薄

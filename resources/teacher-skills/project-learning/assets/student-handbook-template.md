# 学生学习手册模板（活动工具单 workbook 取向）

> 本模板用于第八步产出「学生学习手册」。定位是**学生拿到就能动手做的活动工具单 workbook**，不是设计文档。
> 写作铁律：去掉一切评估语言（如"阶段成功画像""成功标准"），改成学生视角的"你要做什么 / 怎么做 / 小提示"。
> 各工具单的支架与工具，由本项目在第四步实际选定——项目用了 AI 协同才带记录区，设了同伴互评才带反馈卡，不套固定套路。

## 五、使用说明

1. **同伴互评反馈表**：在每阶段成果展示后使用，由其他小组填写，教师需引导"对事不对人"的评价态度
2. **教师观察记录表**：教师在每节课后及时填写，作为过程性评价的核心证据
3. **自我反思表**：项目每个阶段结束后由学生个人填写，培养元认知能力
4. **项目总结反思表**：项目全部结束后由教师填写，作为迭代改进的依据
5. 所有反馈表应纳入学生的"项目档案"，作为综合评价的依据之一

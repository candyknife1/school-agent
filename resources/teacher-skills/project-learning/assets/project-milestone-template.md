## 风险预警与应对策略

| 可能风险 | 预警信号 | 应对策略 |
|----------|----------|----------|
| 进度落后 | 里程碑检查点未按时完成 | 调整课时安排，增加课后辅导 |
| 学生分歧 | 小组内部矛盾 | 介入调解，重新明确角色分工 |
| 成果质量不达标 | 阶段性成果评估低于预期 | 提供额外支架，安排同伴互助 |
| 资源不足 | 材料/场地/专家对接不到位 | 启动备选方案，调整项目设计 |

---

## 使用说明

1. 在项目启动阶段与学生共同填写此模板
2. 将里程碑表格张贴在教室"项目导航页"上
3. 每到达一个里程碑检查点，组织学生自评和教师评估
4. 根据项目实际进展，可动态调整后续里程碑的时间节点
5. 项目结束后，将此模板作为项目档案的一部分存档

# Example: Style Selector

## Input A

```text
明天带美术工具来学校，给我一个低打扰型通知。
```

## Output A

```text
【低打扰型】
温馨提醒：请同学们明天带好美术工具到校，以便正常开展课堂活动。感谢配合。
```

## Input B

```text
周五运动会入场安排，给我三个版本：正式规范型、简短高效型、亲切鼓励型。
```

## Output B

```text
【正式规范型】
请同学们于周五按班级安排准时参加运动会入场，统一着装，按指定位置集合，听从现场指引，有序完成入场流程。

【简短高效型】
周五运动会请同学们按班级要求准时集合、统一着装、听从指引，有序完成入场。

【亲切鼓励型】
周五运动会即将开始，期待同学们精神饱满、整齐有序地完成入场展示，一起展现班级风采。
```

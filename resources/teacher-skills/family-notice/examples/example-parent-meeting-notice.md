# Example: Parent Meeting Notice

## Input

```text
【通知事项】期中阶段家长会
【面向对象】家长
【学段】高中
【时间】5月30日（周五）晚上7:00
【地点】高一（3）班教室
【需要准备或注意事项】请尽量准时参加，如确有特殊情况请提前告知班主任
【通知风格】温和提醒型
【是否需要注意事项清单】是
```

## Output

```text
【温和提醒型】
各位家长，您好。班级拟于5月30日（周五）晚上7:00在高一（3）班教室召开期中阶段家长会，诚邀您按时参加。为便于家校沟通与后续安排，请您尽量准时到场；如确有特殊情况，也请提前与班主任联系。感谢您的理解与配合。

【注意事项清单】
1. 请尽量准时到场参加。
2. 如有特殊情况，请提前告知班主任。
3. 到校后请按班级安排有序入场。
```

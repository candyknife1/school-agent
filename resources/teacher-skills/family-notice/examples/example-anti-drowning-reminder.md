# Example: Anti-Drowning Reminder

## Input

```text
【通知事项】周末防溺水安全提醒
【面向对象】家长与学生
【学段】初中
【时间】本周末
【地点】居家及外出期间
【需要准备或注意事项】不私自下水，不到危险水域玩耍，家长加强提醒
【通知风格】郑重安全型
【是否涉及安全教育】是
【安全主题】防溺水
```

## Output

```text
【郑重安全型】
请家长和同学们共同重视本周末防溺水安全。外出期间请务必远离危险水域，不私自下水，不擅自结伴到河边、池塘边等区域逗留玩耍。也请家长继续做好提醒和关注，共同守护学生周末安全。

【郑重安全型安全提醒补充】
请提醒学生增强规则意识和自我保护意识，不私自下水、不盲目结伴涉水，发现危险情况先远离、先求助，避免把冒险当成尝试。
```

# Example: Activity Showcase Notice

## Input

```text
【通知事项】综合实践活动成果展示
【面向对象】家长与学生
【学段】小学高段
【时间】5月28日（周三）下午3:00
【地点】学校多功能厅
【需要准备或注意事项】学生穿校服，带好作品材料，家长提前10分钟到场
【通知风格】亲切鼓励型
【是否需要注意事项清单】是
```

## Output

```text
【亲切鼓励型】
亲爱的家长朋友们和同学们，5月28日（周三）下午3:00，我们将在学校多功能厅举行综合实践活动成果展示。欢迎大家一起见证孩子们的学习收获与成长表现。请同学们穿好校服、带齐作品材料，也请家长朋友们提前10分钟到场，共同为孩子们加油鼓励。

【注意事项清单】
1. 学生统一穿校服。
2. 带好展示所需作品材料。
3. 家长请提前10分钟到场。
4. 现场请保持有序、安静观展。
```
